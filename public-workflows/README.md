# GALLARDO AI — Public n8n workflows

Public template exports. Configure your own credentials and values before activation.

## Workflows
- School Mail Intelligence
- School Mail Assistant

## Required configuration
Replace the REPLACE_WITH placeholders in each Config node.
Reconnect your own Gmail, Google Sheets and Telegram credentials.
Configure your own OpenRouter access in the relevant HTTP Request nodes.

The original working exports are kept separately and are not included here.
